# Manual-Testing-Project
Manual testing project for the Foodmandu web application covering functional, UI, negative, boundary, responsive, accessibility, security smoke, and exploratory testing. The project includes 92 detailed test cases, test scenarios, a test plan, RTM, defect tracking, test data, and execution dashboard, with 89 passed, 2 failed, and 1 N/A test case.
